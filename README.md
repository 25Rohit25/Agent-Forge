# AgentForge — Agentic AI Developer Workspace

AgentForge is a full-stack, autonomous **Agentic AI Developer Workspace** designed for engineering teams to investigate application incidents, query system health and telemetry, search technical documentation using RAG, and execute operational workflows via natural language.

## Architecture Highlights
- **Frontend**: React, TypeScript, TailwindCSS, Lucide Icons, Vite
- **Backend**: FastAPI, Python 3.12, LangChain, Pydantic v2
- **Data & Vectors**: PostgreSQL with pgvector, Redis, SQLite fallback
- **Agent Capabilities**: Dynamic tool selection, multi-step planning, automated incident root cause analysis, GitHub issue generation
